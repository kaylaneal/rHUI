Remote HistomicsUI (rHUI)
#########################

**rHUI** is a command-line program that runs analyses traditionally done in Histomics UI remotely via the Digital Slide Archive's (DSA) API. 

Check out the :doc:`usage` for further information, including :ref:`Installation` details.


.. note::
    - Project is actively under development!
    - Documentation is currently under construction.
