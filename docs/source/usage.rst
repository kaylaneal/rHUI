Installation
------------

**Environment Requirements:**
- python
- girder-client
- geojson

1. Clone Repository

.. code-block:: console

    git clone https://github.com/kaylaneal/rHUI
    cd rHUI

2. Run rHUI

.. code-block:: console

    python run.py --config config.json --analyses NFT-detection
